
# Marketing Campaign Performance Analysis

## Project Overview
An interactive marketing analytics project using SQL and Power BI to analyze 240 synthetic campaign records across four advertising channels.

The objective is to evaluate advertising performance, revenue contribution, conversions, and marketing efficiency to support data-driven business decisions.

## Tools Used
- MySQL and DBeaver: SQL analysis
- Power BI: Interactive dashboard development
- Power Query: Data cleaning and validation
- DAX: KPI calculations and performance metrics
- Excel: Dataset management

## Key Performance Indicators
- Total Advertising Spend
- Total Revenue
- Total Conversions
- Return on Ad Spend (ROAS)
- Click-Through Rate (CTR)
- Cost Per Click (CPC)
- Conversion Rate
- Cost Per Conversion

## SQL Analysis
The project includes six SQL queries covering:
1. Revenue by advertising channel
2. Conversions by channel
3. Return on Ad Spend
4. Average advertising spend
5. Campaigns generating over 100 conversions
6. Cost per conversion by channel

SQL functions used include SUM(), AVG(), GROUP BY, HAVING, ORDER BY, ROUND(), and NULLIF().

## Key Findings
- Paid Search generated the highest attributed revenue.
- Email achieved the highest ROAS.
- Display Advertising showed comparatively lower advertising efficiency.

## Business Recommendations
- Investigate opportunities to scale high-performing campaigns.
- Evaluate Email's strong ROAS alongside its total revenue contribution.
- Review Display Advertising's targeting and conversion performance before increasing its budget.

## Dataset
This project uses synthetic marketing campaign data created for portfolio development and analytical practice.
